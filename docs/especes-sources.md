**Dessin, pas un fait** : l'hiver, les petits bourgeons verts au bout des branches disent
que l'arbre dort (planche). Dans la réalité, les bourgeons d'hiver d'un pommier ou d'un
cerisier sont plutôt bruns, protégés par des écailles ; le vert est un code du dessin, et
aucun texte du site ne l'affirme.
