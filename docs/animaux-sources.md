# Les animaux parlent : sources des faits

Règle : une réplique de `kind: "fait"` (`src/content/animaux/`) dit quelque chose de vrai sur
l'animal réel ; elle cite une source de ce tableau par son identifiant (`sourceId`), comme
une autre réplique ou les répliques de sommeil (`sleepSourceId`) quand elles s'appuient sur
un fait. Une source ne compte que si sa ligne cite le texte (colonne « Ce que dit la
source », entre « », “ ” ou " ") : sans citation, le build échoue (`scripts/check-data.ts`),
ainsi que les tests (`src/content/animaux/check.test.ts`). Comme pour les espèces
(`especes-sources.md`) : source fiable, lue, citation reprise telle quelle ; un fait non
confirmé n'entre pas, et le texte des répliques n'est jamais réécrit ici.

Toutes les sources ont été lues le 8 octobre 2026 (celles de l'écureuil et de l'abeille le
9 octobre 2026). Vikidia refuse les robots sur ses pages :
les articles ont été lus par son API (texte source de la révision indiquée).
